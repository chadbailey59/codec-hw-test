Video codec hardware test

Browsers tell web pages whether a video codec runs in dedicated hardware. This page checks whether those answers are true. For each codec your browser supports, it compares what the browser predicts with the encoder and decoder it uses when it sends and receives video.

The test takes about 5 minutes. It uses your camera, but no video leaves your computer: the call runs between two connections inside this page. When it finishes, it sends the results (browser, operating system, GPU name, and codec measurements) to Chad Bailey at Daily. It doesn't send any video.

  1. Close other video calls and tabs that use the camera.
  2. Click Run test and allow camera access.
  3. Keep this tab in front until the test finishes.
Optional: add your browser's own hardware report (about 1 minute)

Your browser keeps an internal report of which video codecs it can run in hardware. Adding it lets us check the test against it. Only the video codec lines are sent, and you can see them below before you run the test.

  1. Copy this address: about:support
  2. Open a new tab, paste the address, and press Enter. Firefox doesn't let web pages open it for you.
  3. Near the top of that page, click Copy raw data to clipboard.
  4. Come back to this tab and click Paste report, or paste into the box.
  1. Copy this address: chrome://gpu
  2. Open a new tab, paste the address, and press Enter. The browser doesn't let web pages open it for you.
  3. Near the top of that page, click Copy Report to Clipboard. If you downloaded the report as a file instead, choose it with Upload report file.
  4. Come back to this tab and click Paste report, or paste into the box.
